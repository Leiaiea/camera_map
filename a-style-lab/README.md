# A 侧静态样式实验区

这里专门用于调整 A 侧前端的静态视觉样式，不承载业务交互和数据逻辑。

## 本地预览

预览页会直接引用 `A_src/src/styles/` 下的现有样式文件，因此修改 A 侧样式后刷新即可看到效果。

从工作区根目录启动静态服务器：

```bash
python -m http.server 8791
```

然后访问：

```text
http://127.0.0.1:8791/a-style-lab/
```

注视页独立验收：访问 `http://127.0.0.1:8792/a-style-lab/gaze-attention-preview.html` 查看显影窗和温柔注视圈；访问 `capture-preview.html` 查看上一版完整确认面板。两页均只用于 UI 状态验收，不连接真实相机或业务数据。

页面顶部可以切换 Guide、Capture、Transition、Map 四个静态页面样例。顶部切换仅属于预览工具，不会进入 A 侧产品代码。

## 样式文件边界

- `A_src/src/styles/tokens.css`：颜色、字体、间距、阴影等公共变量。
- `A_src/src/styles/global.css`：全局重置与页面基础结构。
- `A_src/src/styles/app.css`：当前 A 侧主要页面样式；后续可按页面拆分。
- `a-style-lab/preview.css`：仅属于本实验区的预览容器和样例补充样式，不合并回 A 侧。

## 当前字段与交互边界

本实验区只开发视觉原型：不新增产品字段、不接入真实业务状态或数据逻辑、不修改地图数据和定位逻辑。地图样例只展示现有 class 的视觉效果。

`paper-tear-preview.html` 中的录音、文字、录音完成标识和动态音量柱均为本地视觉状态模拟；**不得**请求麦克风权限、调用 Web Audio API、接入语音识别或保存音频/文字。录音结束后恢复原底部按钮组，仅在麦克风图标上显示完成标识，不产生独立声音组件；真实采集链路须在产品代码中另行接入。

## 地图到拍摄页的纸张转场约定

`paper-tear-preview.html` 保留连续的 A/B/C 视觉状态机，用于验收同一张纸的撕开轨迹、底部控件切换，以及 A 左侧引导半屏浮层。它是转场覆盖层的视觉原型，不是产品页面路由。

- **A（地图页）**：归 `MapPage` 所有，使用真实、可交互的高德地图；保留地图页的拍摄、引导和归档控件。左侧引导按钮打开半屏种子浮层。
- **B（交接态）**：相机预览已在底层启动；`MapToCaptureTransition` 覆盖层仍显示按下入口时取得的地图快照，并从 A 的同一条纸边连续撕开。此时底部切换为录音、文字与快门。
- **C（拍摄页稳定态）**：纸层继续沿 B 的纸边退场；已拍摄画面缩小进入圆角白框，周边相机画面模糊化，形成照片显影样式。之后卸载覆盖层，只留下 `CapturePage` 的相机、录音、文字和快门控件。

产品实现不得在 A 点击后用路由跳转或重新加载 B。正确实现是由同一应用根节点暂时同时保留 `MapPage`、预挂载的 `CapturePage` 和 `MapToCaptureTransition` 覆盖层；覆盖层完成后再卸载 `MapPage` 与自身。这样 A → B 的纸边、相机启动与控件状态才连续。

### 快照输入契约

转场组件的输入是一个普通图片 URL，建议产品代码命名为 `mapSnapshotUrl: string`。B/C 覆盖层**不得**继续持有或操作高德地图实例；地图只作为这一张不可交互的图片存在。

本地原型通过查询参数接收该值：

```text
http://127.0.0.1:8791/a-style-lab/paper-tear-preview.html?mapSnapshot=<已编码的图片URL>
```

未传 `mapSnapshot` 时，原型回退到 `a-style-lab/map-paper.png`，仅用于视觉验收。高德地图瓦片和 DOM 不能假设可被浏览器直接截图；地图接入方需要通过可用的静态地图能力、服务端截图或地图适配层产出可访问的图片 URL，再传给拍摄流程。

### 实验区验收入口

- `paper-tear-preview.html`：连续验收 A → B → C。A 点击中央拍摄按钮后在同一页面撕开进入 B；B 点击快门进入 C。A 左侧按钮打开半屏种子浮层。

## 当前优化进度与注意事项

- [x] A/B/C 保持在同一张预览页面中，A → B 使用连续撕纸动画，B → C 延续当前裂缝退场。
- [x] A 阶段恢复原有引导、拍摄、归档控件，并复用 `paper-tear-guide-sheet.js` 的半屏引导视觉。
- [x] B/C 阶段控件切换为录音、快门、文字输入；录音状态下底部操作区由录音控件接管，结束后恢复三键。
- [x] C 阶段增加照片显影：照片缩小至圆角白框，周边相机画面模糊；照片框与相机层均不可点击，不提供放大或全屏查看。
- [x] 玻璃 `bridge` 只作为背景层：必须保持 `pointer-events:none` 且低于 `.action`，按钮层使用更高 `z-index` 和 `pointer-events:auto`。
- [x] 地图纸层支持 `?mapSnapshot=` 图片 URL 注入；未传参时回退 `map-paper.png`。

注意事项：

- 本页只做视觉状态验收，不请求麦克风、不调用 Web Audio API、不保存录音或文字，也不承载真实业务数据。
- 录音中按钮暂时不可用是设计行为，不是故障；应通过录音控件的“完成”状态结束后再恢复快门和文字按钮。
- 后续开发不要通过新增全屏层、图片点击监听或覆盖 `.actions` 的末尾样式改变上述命中关系；新增样式应先检查层级和 `pointer-events`。
- 产品接入必须由同根覆盖层承接 `MapPage → MapToCaptureTransition → CapturePage`，不要通过页面跳转重新播放撕纸动画。

## 合并方式

样式调整完成后，在样式分支中确认：

```bash
git diff --name-only
```

理想结果只包含 `A_src/src/styles/**`。提交后由 A 侧执行：

```bash
git cherry-pick <样式提交号>
```

如果修改了 `a-style-lab/preview.css` 或 README，这些文件只用于实验区记录，不应混入 A 侧产品发布包。
