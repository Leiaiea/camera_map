# 个人地图｜交互探索

这是一个用于探索手机端「拍照 + 空白地图」体验的静态网页原型。

## 当前状态

直接在浏览器打开 `index.html`。首屏固定为“调试菜单”。当前有一个入口：

- **01 空降快递**：在拍照页拍下用户提供的教堂照片，系统完成教堂主体识别、抠图和快递装箱；随后进入地图页观看快递包裹由降落伞送达、打开并留下这座教堂。
- **02 景色扫描**：在拍照页像扫描仪一样框选整片景色；地图页则让这片景色通过全息投影逐层生成在空白地图上。
- **03 画框传递**：在拍照页把景色收进画框；地图页的一位小画家会拿着笔刷，把教堂一笔笔画到地图中。
- **04 棱镜海市蜃楼**：在拍照页用棱镜采样照片中的光；地图页让这束光折射并生成一座短暂的教堂海市蜃楼。
- **05 魔法召唤**：在拍照页让魔法阵收走教堂主体；地图页由一群小巫师围绕法阵举行仪式，将教堂从光芒中召唤出来。
- **06 任意门**：在拍照页把教堂主体缩小并推入任意门；地图页由小人从门后把教堂推出，门随后消失。

## 后续扩展方式

每个版本维持两个体验页面：拍照页与地图页。新增版本时，在 `index.html` 增加调试入口及这一对页面；样式集中在 `styles.css`，交互逻辑在 `app.js`。
