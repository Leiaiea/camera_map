# 个人地图｜交互探索

这是一个用于探索手机端「拍照 + 空白地图」体验的静态网页原型。

## 当前状态

直接在浏览器打开 `index.html`。首屏固定为“调试菜单”。当前有一个入口：

- **01 空降快递**：在拍照页拍下用户提供的教堂照片，系统完成教堂主体识别、抠图和快递装箱；随后进入地图页观看快递包裹由降落伞送达、打开并留下这座教堂。
- **02 景色扫描**：在拍照页像扫描仪一样框选整片景色；地图页则让这片景色通过全息投影逐层生成在空白地图上。
- **03 画框传递**：在拍照页把景色收进画框；地图页的一位小画家会拿着笔刷，把教堂一笔笔画到地图中。
- **04 棱镜海市蜃楼**：在拍照页用棱镜采样照片中的光；地图页让这束光折射并生成一座短暂的教堂海市蜃楼。
- **05 魔法召唤**：在拍照页让魔法阵收走教堂主体；地图页由一群小巫师围绕法阵举行仪式，将教堂从光芒中召唤出来。
- **06 任意门**：在拍照页把教堂主体缩小并推入任意门；地图页由小人从门后把教堂推出，门随后消失。
- **07 施工图建造**：在拍照页将教堂照片转换为施工图；地图页由工头指挥工人，按蓝图把教堂搭建到地图上。
- **08 撕页染色**：在拍照页把教堂主体从照片上撕下；地图页让碎片飘落、融化并染色，长出绘画风格的教堂。
- **09 邮差来信**：在拍照页把教堂主体装进信封；地图页由骑自行车的邮差取出信封、打开并把主体放到地图上。
- **10 地下宝藏**：在拍照页把教堂主体放入宝箱；地图页由考古学家发现线索并召集人挖掘，从地下挖出主体。
- **11 抓娃娃机**：在拍照页让机械爪抓住缩小的教堂主体；地图页机械爪横向搬运并松手，让主体落在地图上。
- **12 彩云下雨**：在拍照页让白云吸取教堂照片的颜色变成彩云；地图页彩色的雨染过地面，绘出教堂主体。
- **13 撕开地图**：拍照后地图表面被撕开一道口子，教堂主体从裂缝下方升起并留在地图上。
- **14 天眼海市蜃楼**：从一只不断眨动的眼睛视角拍摄，闭眼留下主体残影；地图天空睁开天眼，以激光投映出主体的海市蜃楼。
- **15 钢笔线稿**：地图上出现一支巨大的钢笔绘制主体线稿，线稿逐渐变成写实主体，钢笔随后消失。

- **16 纸飞机投递**：桌面上的教堂照片纸经过折角、收翼与对折成为纸飞机；纸飞机盘旋飘落到地图后退场，并留下照片中的主体抠图。
- **17 心情色流**：魔法棒读取照片的心情色温，将教堂化成金橙色粒子；地图页中魔法棒引导粒子流向目标点，并重新汇聚成带有余辉的教堂主体。
- **18 邮票来信**：照片进入邮票齿孔相框，盖下邮戳并投入邮箱；地图页由快递员沿路线送信，并把教堂邮票留在目的地。
- **19 钻石信物**：照片中的光凝成一颗折射着教堂影子的钻石，小鸟将它衔走；地图页中小鸟飞来并把钻石轻轻放下。
- **20 蚂蚁搬家**：照片装进边缘不齐的复古牛皮纸并卷起，小蚂蚁组成搬运队；地图页中蚂蚁把纸卷搬到目标点并重新展开。
- **21 花苞收藏**：照片被花瓣围成花朵取景框，拍下后花瓣闭合成花苞；花苞落入地图、长出根茎并重新开放。
- **22 窗景迁移**：照片像一片真实窗景，木质百叶窗在拍摄后关闭；地图页中整扇窗出现并重新打开，让景色抵达。
- **23 胶片滚映**：复古相机按下快门后吐出连续胶片，胶片卷入胶卷；胶卷滚到地图目标点后展开并显出教堂画面。

## 后续扩展方式

每个版本维持两个体验页面：拍照页与地图页。新增版本时，在 `index.html` 增加调试入口及这一对页面；样式集中在 `styles.css`，交互逻辑在 `app.js`。
