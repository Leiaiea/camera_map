# 高德个性化地图样式规格 · v1

此文件是高德个性化地图编辑器的人工配置清单。创建、保存并发布后，将生成的样式 ID 填入 `config.js`：

```js
mapStyle: "amap://styles/你的样式ID",
```

## 色彩铁律

地图底图只允许使用下列六种颜色；透明度变化仅用于弱化，不引入新的色相。

| 地图元素 | 色值 | 配置说明 |
|---|---:|---|
| 背景 / 空白区域 | `#F3F3F5` | 区域面、陆地底色 |
| 道路 | `#FFFFFF` | 仅保留的普通道路填充 |
| 水域 | `#BBD5E2` | 河流、湖泊、水库等 |
| 绿化 | `#C2D4AA` | 公园、绿地、植被面 |
| 建筑 | `#E8E8EA` | 建筑面 |
| 描边 / 边界线 | `#C9C7CA` | 行政区、建筑、水域及道路描边 |

## 编辑器设置

在高德个性化地图编辑器中以“标准”样式为基底，逐项设置：

1. **区域面**：陆地 / 空白区域使用 `#F3F3F5`；绿地使用 `#C2D4AA`；水域使用 `#BBD5E2`；所有边界描边使用 `#C9C7CA`。
2. **道路**：保留普通道路，填充使用 `#FFFFFF`、描边使用 `#C9C7CA`；高速、快速路、铁路和地铁线设为隐藏。
3. **建筑**：建筑填充使用 `#E8E8EA`，描边使用 `#C9C7CA`。
4. **标注**：全部隐藏。代码仍保留 `showLabel: false` 作为第二道保障。
5. **POI**：全部隐藏。代码不请求 `point` 要素作为第二道保障。
6. 发布样式，将样式 ID 填入本地 `config.js` 并强制刷新预览页。

## 验收

- 地图中没有文字、POI 图标、高速、快速路、铁路或地铁线。
- 普通道路为纯白色，周围以 `#C9C7CA` 轻描边。
- 水域、绿化、背景、建筑与描边仅使用本规范的色值。
- 页面 CSS 不使用地图滤镜，确保色值不被二次改变。
