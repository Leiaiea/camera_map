# 记忆地图 · 世界渲染模块

本目录预留给 B（地图 / 世界渲染）侧开发。按可验收的小步骤推进；具体技术选型与 A/B 数据接口均以实际验证和双方确认结果为准，不在这里提前定稿。

## 当前验收：01 高德地图本地预览

已提供一个零依赖 Web 预览页，用于确认高德地图能正常接入、拖动和缩放。它是独立 Spike，不是最终 App 框架。

1. 打开 [config.js](./config.js)，填入高德控制台中 **Web端（JS API）** 的 `amapKey` 和 `securityJsCode`。
2. 用本地静态服务器打开本目录。例如在本目录执行：`npx serve .`，再访问终端输出的网址。若从工作区根目录启动服务，则访问 `/memory-map-world/`。
3. 验收：显示高德官方 `whitesmoke` 低饱和灰白底图；无文字、无 POI 图标、无高速/地铁；保留普通道路；可拖动、滚轮/双指缩放；左上角状态为“地图图面已加载”。

`config.js` 已被 Git 忽略，不会提交凭据；`config.example.js` 是可提交的配置模板。本地明文安全密钥仅用于开发预览，正式环境改用服务端代理。


### 当前阶段向 A 侧所需字段

本轮“定位到这里”仅由地图预览页自行请求浏览器位置，**尚不要求 A 提供字段**，且不会保存定位结果。

定位验收通过后，地图模块对 A 的最小字段需求如下；它们只适用于“新记忆落图”，尚待双方确认后才进入共享类型：

| 字段 | 类型 | 来源 | 用途 | 状态 |
|---|---|---|---|---|
| `lngGcj02` | `number` | 快门时单次定位 | 地标的经度落点 | 待确认 |
| `latGcj02` | `number` | 快门时单次定位 | 地标的纬度落点 | 待确认 |
| `locationAccuracy` | `number`（米） | 定位结果 | 染色半径和低精度降级 | 待确认 |
| `locatedAt` | `number`（毫秒时间戳） | 定位完成时刻 | 判断定位是否与拍摄时刻相近 | 待确认 |

后续不会擅自增加字段；每个下一步都会先在此表新增需求、验收后再与 A 确认。

### 当前底图策略

- `showLabel: false`：隐藏底图文字与 POI 信息。
- `showIndoorMap: false`：关闭室内地图。
- `features: ["bg", "road", "building"]`：保留区域面、普通道路与建筑；隐藏 POI。
- `mapStyle: "amap://styles/whitesmoke"`：使用高德官方低饱和灰白底图，不使用 CSS `filter` 处理地图 DOM。
- `mapToneColor: "#FFFFFF"` 与 `mapToneOpacity: 0.10`：在底图之上叠加极轻白色提亮层，避免洗掉建筑与道路描边；未来世界图层必须位于该层之上。
- 四周雾化：已移交 UI 层实现，地图模块不再渲染 `map-fog`。
- 自适应 3D 视角：`viewMode: "3D"`、`rotation: 0`；俯仰角随缩放级别从约 `18°`（12 级）连续过渡到约 `58°`（20 级），禁用用户旋转与倾斜，保留平移与缩放。
- 初始缩放：`initialZoom: 20`，在北京纬度的手机视口中约为 10 米量级比例尺；比例尺会随纬度和屏幕尺寸略有变化。

详见 [MAP_STYLE_SPEC.md](./MAP_STYLE_SPEC.md)。地图模块不再提供四周雾化，避免与 UI 层的最终效果重复。

### 地图实例与数据更新

`AMap.Map` 在页面生命周期内只创建一次。后续新增、更新或删除用户内容时，不重新加载 JS API、不重新创建地图，也不重置用户当前的缩放与视野。

地图就绪后会暴露 `window.memoryMapWorld`：

```js
window.memoryMapWorld.upsertContent(id, record);
window.memoryMapWorld.removeContent(id);
```

上述调用只发出内容更新事件，供后续世界图层消费；当前尚未确认正式地标数据结构，因此 Demo 数据与真实业务数据仍然分离。

### Demo 固定中心点（正式接入前删除）

目前 `config.js` 的 `initialCenter` 固定为本次浏览器定位得到的 GCJ-02 坐标 `[120.563271, 32.390748]`，每次打开预览页都会从这里开始。它仅用于周边场景的 Demo 调试，不写入任何业务数据。

正式接入 A 侧时，需要删除这段 Demo 坐标注释和固定值，并改为由产品流程提供地图初始中心点；“定位到这里”按钮可以保留为用户主动调整视角的能力，但不会再持久化位置。

### 自适应视角

地图保持 3D 模式，并随缩放级别自动改变俯仰角：缩放至 `20` 级时约为 `58°`，突出周边环境的空间感；缩小至 `12` 级时约为 `18°`，便于浏览更大区域。两者之间连续过渡；地图实例不会因此重建。

3D 天空使用高德 JS API 的独立 `skyColor` 参数，当前默认为低饱和雾蓝 `#DCE8EC`。它不影响底图、建筑、地面染色和贴纸；如需微调，只需在 `config.js` 修改 `skyColor` 覆盖默认值。地图模块不再渲染四周雾化，雾化效果由 UI 层负责。

建筑显示通过 `features: ["bg", "road", "building"]` 与 `showBuildingBlock: true` 双重开启；同时使用低饱和的 `roofColor` / `wallColor` 保留楼块轮廓。若仍觉得建筑过淡，应优先降低 `mapToneOpacity` 或边缘雾化强度，而不是关闭建筑图层。

### Demo 照片贴纸

预览素材位于 `assets/memories/<id>/`：每组包含统一命名的 `photo.jpg`（原图）和 `sticker.png`（透明贴纸）。每张贴纸都在 `demo-memory-records.js` 中拥有固定的虚拟 `id`、拍摄时间与 GCJ-02 坐标；坐标相对 Demo 中心点扩大分散，拖动或缩放地图时会随位置移动。贴纸使用统一的 `56 × 56px` 显示区域并完整包含，不裁切细长或扁平的贴纸；其下方复制贴纸轮廓生成统一右下方向的压扁接触阴影，呈现贴纸坐落在地图上的感觉。贴纸层保持清晰，四周雾化由 UI 层负责。

这是纯 Demo 素材。正式接入时，A 侧需要为每个可显示的贴纸至少提供以下字段；字段名尚未和 A 侧敲定：

| 字段 | 说明 | 约束 |
| --- | --- | --- |
| `id` | 记忆记录的稳定唯一标识 | `string`，不编码时间或坐标，更新或删除时保持不变 |
| `capturedAt` | 拍摄时间 | ISO 8601 时间字符串，含时区 |
| `photoUrl` | 原图的可访问地址 | `string`，当前 Demo 为 `photo.jpg` |
| `stickerUrl` | 已生成贴纸 PNG 的可访问地址 | `string`，透明背景 PNG |
| `groundTintColors` | 地面染色三色调色板 | `[string, string, string]`，如 `["#6B8AA8", "#A8B6A0", "#D7B7A0"]`；由原图提取后的派生值 |
| `lngGcj02` | 贴纸对应地点经度 | `number`，GCJ-02 |
| `latGcj02` | 贴纸对应地点纬度 | `number`，GCJ-02 |
| `accuracyMeters` | 定位精度 | `number`，单位米；无有效精度时需明确约定空值规则 |

正式接入时，应删除 `demo-memory-records.js` 和相关 `createDemoStickers` 逻辑，改为使用上述确认后的真实记录。

`groundTintColors` 应在拍摄完成、原图可用后提取并随记录保存。地图端不应在每次打开时重新读取大图取色；若提取失败，可不传该字段并使用三项中性默认色。当前 Demo 将三色渲染为多色斑叠加、自然透明渐隐的水彩晕染，而不是规则单色圆斑。


## 模块目标

消费完整落库的 `MemoryRecord`，在风格化地图上渲染会随真实地理坐标生长的私人记忆世界：染色、地标、地名、生态、显影动画、缩放浏览与记忆地图海报。

产品判断标准：世界大于产品、过程大于目的地、凝视大于占有。地图不是打卡墙，也不是相册或信息流。

## 负责范围

- 高德地图接入与灰白、无文字无图标的底图风格化。
- 世界图层：染色晕染、地标、地名、生态动态元素。
- 地图手势、缩放层级、坐标投影与相机同步。
- 新记忆的显影动画与记忆地图海报生成。
- `MemoryRecord` 落库之后的读取、分组、褪色及渲染状态维护。

不负责：相机、快门、录音、图片文件管理、抠图/主体识别、情绪选择 UI、应用导航与权限弹窗系统接入。

## 暂定合并方向（未确认，勿据此实现）

未来数据会以共享的 `MemoryRecord` 为基础，但字段尚未和 A 定稿。坐标约束已经明确：任何进入地图模块的坐标必须为 **GCJ-02**；禁止混用 WGS-84 或 BD-09。

地图模块监听：

```ts
memoryCreated(record: MemoryRecord)
memoryUpdated(record: MemoryRecord)
memoryDeleted(id: string)
```

地图模块向外提供可嵌入的地图视图，并通过以下回调将地标详情交还给 A：

```ts
onLandmarkTapped(record: MemoryRecord): void
```

字段一经双方确认，才遵循：更新协作契约文档 → 双方同步实现 → 升版本号。不得在本模块中私自改写共享数据结构。
